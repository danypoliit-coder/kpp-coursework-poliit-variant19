# Greenery Care 🌳

## Інформаційна система догляду за міськими зеленими насадженнями

**Greenery Care** — клієнт-серверна інформаційна система для обліку міських зелених насаджень, проведення оглядів дерев, формування заявок на виконання робіт та контролю їх виконання.

Проєкт розроблено в межах курсової роботи з використанням Java, JavaFX, Apache Tomcat та MySQL.

## Основні можливості

- Облік дерев: додавання, перегляд, редагування та видалення.
- Пошук дерев за ідентифікатором, породою або адресою.
- Реєстрація та редагування результатів оглядів.
- Створення заявок на проведення робіт.
- Фільтрація заявок за статусом.
- Контроль життєвого циклу заявок.
- Формування та облік нарядів на виконання робіт.
- Розрахунок інтегрального показника ризику.
- Фоновий імпорт дерев із CSV-файлів.
- Відображення прогресу імпорту та журналювання подій.
- Графічний інтерфейс із CSS-оформленням.
- Взаємодія між клієнтом і сервером через HTTP API у форматі JSON.

## База даних

Для зберігання інформації використовується база даних `greenery_care`.

Основні таблиці:

- `trees` — відомості про дерева.
- `inspections` — результати оглядів.
- `work_requests` — заявки на виконання робіт.
- `work_orders` — наряди на виконання робіт.

Між таблицями встановлено зв'язки за допомогою зовнішніх ключів.

## Розрахунок інтегрального показника ризику

У системі використовується формула:

\[
I = 0.40F_1 + 0.35F_2 + 0.25F_3
\]

де:

- **F₁** — показник технічного стану дерева;
- **F₂** — інтенсивність перебування людей;
- **F₃** — геометричність втручання.

Результат розрахунку відображається з точністю до двох знаків після коми.

## Встановлення та запуск

### Необхідне програмне забезпечення

- JDK 21
- Apache Maven
- MySQL
- Apache Tomcat 9
- IntelliJ IDEA або інше середовище розробки з підтримкою Java

### 1. Підготовка бази даних

Створіть базу даних MySQL:

```sql
CREATE DATABASE IF NOT EXISTS greenery_care
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;
```

Створіть необхідні таблиці відповідно до SQL-схеми проєкту та налаштуйте параметри підключення до MySQL.

### 2. Збирання серверної частини

Перейдіть до папки `server`:

```bash
cd server
mvn clean package
```

Після збирання WAR-файл розташовуватиметься за шляхом:

```text
server/target/greenery-care.war
```

Розгорніть WAR-файл у Apache Tomcat 9 та запустіть сервер.

### 3. Перевірка API

Після запуску сервера API доступний за адресами:

```text
http://localhost:8080/greenery-care/api/trees
http://localhost:8080/greenery-care/api/inspections
http://localhost:8080/greenery-care/api/requests
http://localhost:8080/greenery-care/api/orders
```

### 4. Запуск клієнтської частини

Перейдіть до папки `client`:

```bash
cd client
mvn javafx:run
```

Після запуску відкриється графічний інтерфейс Greenery Care.

## CSV-імпорт

Програма підтримує імпорт дерев із CSV-файлів у кодуванні UTF-8.

Приклад структури:

```csv
species,address,latitude,longitude,technical_state,people_intensity,green_area
Клен,вул. Європейська 10,49.590000,34.550000,75.00,60.00,80.00
Липа,вул. Соборності 15,49.590500,34.551000,65.00,40.00,70.00
```

Імпорт виконується у фоновому потоці JavaFX Task.

Програма відображає прогрес виконання, кількість імпортованих та пропущених записів. Повторний імпорт тих самих даних може призвести до створення дублікатів.

## Тестування

Для перевірки бізнес-логіки серверної частини використовується JUnit 5.

Запуск тестів:

```bash
cd server
mvn clean test
```

Перевірка збирання:

```bash
mvn clean package
```

Також проведено перевірку взаємодії клієнта, HTTP API та бази даних.

## Журналювання
